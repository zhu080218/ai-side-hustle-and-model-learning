## 6. 项目验收清单

RAG 项目：
- [ ] 50–100 条测试集已标注（问题 → 正确文档 → 期望要点）
- [ ] Hit@5 ≥ 80%，Recall@10 ≥ 85%
- [ ] 无据问题拒答率 ≥ 90%
- [ ] 答案带引用编号，抽查 20 条无编造
- [ ] 文档更新后 24 小时内索引可同步

微调项目：
- [ ] 训练/验证集无重叠
- [ ] 格式遵从率 ≥ 90%（50 条抽测）
- [ ] 通用能力回归测试通过（下降 ≤ 5%）
- [ ] 训练与推理模板完全一致
- [ ] 有基线对比（微调前 vs 后）

部署项目：
- [ ] 压测：并发 …… 下 P95 延迟 ≤ …… ms
- [ ] 单次成本 …… 元，与 API 方案对比有结论
- [ ] 有回滚方案与监控指标
